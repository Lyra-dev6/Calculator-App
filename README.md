# Calculator App
- A beautiful, minimalist dark-mode calculator. Fast, responsive, and tactile.
# Overview
- My second web development project: a fully functional iPhone-style calculator. Focused on mastering CSS Grid, button interactions, and JavaScript math functions.
# Features
- Dark mode
- Different coloured buttons for different purposes(like black for numbers, gray for clear and percentage and orange for basic equation symbols)

# What I learned
- How to set the buttons' colours using HTML as well as CSS(<div button="(colour)" onclick=)
- The 'eval(display.value);' on JavaScript to calculate my numbers
- How JavaScript inputs data from HTML
- Found out how important it is to link JS to HTML
